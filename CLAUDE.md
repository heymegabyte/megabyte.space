# megabyte.space — Cloudflare OS deployment

This repo deploys [cloudflare/cloudflare-os](https://github.com/cloudflare/cloudflare-os) (pinned submodule) to **https://megabyte.space** via the [cloudflare-os-starter](https://github.com/cloudflare/cloudflare-os-starter) wrapper. Six Workers: `megabyte-os` (router, owns the custom domain) + `megabyte-os-backend` (Workshop) + `megabyte-os-context` + `megabyte-os-scheduler` + `megabyte-os-custom` + `megabyte-os-errors`.

## Commands

- `pnpm check` — validate `deployment.jsonc` + dry-run every Worker (run before every deploy)
- `pnpm deploy` — build + deploy all six Workers in dependency order
- `node scripts/verify-prod.mjs` — post-deploy prod assertions (Access gate, service-token app shell, www→apex)

## Auth

- Wrangler auth: the scoped `CLOUDFLARE_API_TOKEN` from `get-secret` LACKS Workers scopes (fails code 10000). Use the global-key fallback: `unset CLOUDFLARE_API_TOKEN; export CLOUDFLARE_API_KEY=$(get-secret CLOUDFLARE_API_KEY) CLOUDFLARE_EMAIL=blzalewski@gmail.com CLOUDFLARE_ACCOUNT_ID=84fa0d1b16ff8086dd958c468ce7fd59`.
- Sign-in: Cloudflare Access (Zero Trust org `manhattan.cloudflareaccess.com`), app "Megabyte OS" on the apex. Admins: hey@megabyte.space, blzalewski@gmail.com. Login via Authentik OIDC or email one-time PIN.
- E2E service token `megabyte-os-e2e` (client id `e276fb6a924b2419a3f216c9eb131291.access`) — pass `CF_ACCESS_CLIENT_ID`/`CF_ACCESS_CLIENT_SECRET` to `verify-prod.mjs`. Rotate via Access API if the secret is lost.

## Gotchas

- Querying the apex while it had no address record poisons local negative DNS cache → `verify-prod.mjs` reports ENOTFOUND false-RED after deploy. Fix: `sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder`, or cross-check via `dig @1.1.1.1` + `curl --resolve`.
- `wrangler.prod.jsonc` files are GENERATED by `scripts/deploy.ts` and gitignored — edit `deployment.jsonc` only.
- The zone redirect ruleset (`http_request_dynamic_redirect`) carries pre-existing rules (`/source.sh`, `public.megabyte.space/github-awesome.json`) plus our `www → apex` 301. Redirects run before Access + the Worker — don't remove them.
- AI models run through AI Gateway `megabyte-os` (Workers AI provider, no API key). Add anthropic/openai providers in `deployment.jsonc` + gateway-stored keys.

## Upgrades

Bump the `cloudflare-os` submodule to a reviewed upstream release, then `pnpm check` + `pnpm deploy` (see README § Operations and upgrades).
