# Megabyte OS — Agent pilot (estate idea #6)

Pilots ONE OS agent on the **Cloudflare Agents SDK** (`agents` npm, `Agent` base class) to establish
the pattern for rebuilding the estate's agent surfaces on it. Standalone worker `megabyte-os-agent`
(zero apex risk) at `megabyte-os-agent.manhattan.workers.dev`.

## What it demonstrates (the #6 primitives)

- **Durable session** — `OSAgent` is a SQLite-backed Durable Object; a per-session turn counter +
  conversation history persist across requests via `this.setState` / `this.state`. Each
  `/agents/os-agent/<session-id>` is an independent durable instance.
- **Sub-agents** — `OSAgent` delegates live-flag grounding to a `FlagsResearcher` child via
  `this.subAgent(FlagsResearcher, "flags")` (discovered via `ctx.exports`, no binding).
- **Grounded + Workers AI** — answers are grounded on real OS facts + the live `/api/flags` the
  sub-agent fetches, generated by Workers AI (`env.AI`, `@cf/meta/llama-3.3-70b-instruct-fp8-fast`),
  fail-soft. A per-session turn cap (durable state) guards the cost-bearing LLM.

## HTTP via RPC (not routeAgentRequest)

`routeAgentRequest` is WebSocket/`useAgent`-oriented and rejects plain HTTP POSTs ("Invalid request").
The worker routes `/agents/os-agent/<id>` server-side via **`getAgentByName(env.OSAgent, id)` + RPC
methods** (`ask()`, `info()`) — the SDK's documented server-side-RPC path.

## Use + verify

```bash
B=https://megabyte-os-agent.manhattan.workers.dev/agents/os-agent
curl -s "$B/mysession" -H content-type:application/json -d '{"message":"what is megabyte os?"}'
curl -s "$B/mysession" -H content-type:application/json -d '{"message":"what did I just ask?"}'  # remembers (durable)
curl -s "$B/mysession"                                                                            # GET session info
```

Verified live: grounded LLM answer using the live `native_os_only` flag; durable session (turns
increment + prior turn remembered); independent per-session state.

## Deploy

```bash
cd os-agent && npm install && npx wrangler deploy
```
